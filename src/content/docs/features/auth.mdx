title: 认证
---

认证使用 Better Auth 和 PostgreSQL Drizzle adapter，入口位于 `src/features/auth/auth.server.ts`，API 路由位于 `/api/auth/$`。

## 能力

- 邮箱密码注册与登录
- 邮箱验证、找回密码和删除账号
- Google/GitHub OAuth，可选且成对配置
- 管理员角色、封禁和模拟登录
- 数据库存储的认证端点限流
- 会话 Cookie cache

本地配置写入 `.env`。`BETTER_AUTH_SECRET`、`BETTER_AUTH_URL` 和 `DATABASE_URL` 必填；OAuth、Resend 与 Turnstile 可选。

认证限流表的 `last_request` 使用 PostgreSQL `bigint`，因为 Better Auth 存储的是毫秒时间戳，数值超过 32 位 `integer` 范围。升级已有数据库时必须执行 `pnpm db:migrate` 以应用对应迁移。

生产必须配置 Resend，才能可靠完成邮箱归属验证与密码重置。留空只适合本地开发降级。

所有受保护 server function 都必须在服务端调用 `readUser`、`requireUser` 或管理员断言，隐藏按钮不能替代授权。
