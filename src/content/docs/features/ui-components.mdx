FlareStarter 提供了一套轻量、开箱即用的 UI 规范。在 `src/components/ui` 目录下，包含了一系列基础的交互组件。

## 样式方案 (Tailwind v4)

本项目使用了最新的 **Tailwind CSS v4** 进行样式管理。
主要的全局样式定义在 `src/styles/app.css` 中：

```css
@import 'tailwindcss';
@plugin 'tailwindcss-animate';

@theme {
  --color-border: hsl(var(--border));
  --color-input: hsl(var(--input));
  /* 其他主题变量 */
}
```

## 基础组件 (Primitives)

绝大部分的基础组件是基于 [Radix UI](https://www.radix-ui.com/) 无头组件封装的（类似于 shadcn/ui 的设计模式）。
你可以直接从 `src/components/ui/` 中导入它们。

### 使用范例

```tsx
import { Button } from '@/components/ui/button'
import { Input } from '@/components/ui/input'
import { Label } from '@/components/ui/label'

export function LoginForm() {
  return (
    <div className="grid gap-4">
      <div className="grid gap-2">
        <Label htmlFor="email">邮箱</Label>
        <Input id="email" type="email" placeholder="m@example.com" />
      </div>
      <Button type="submit">登 录</Button>
    </div>
  )
}
```

### 如何添加新组件

当前项目已完成 **shadcn CLI** 的配置与自定义第三方注册表的集成，添加新组件非常简便。

#### 1. 添加官方 shadcn/ui 组件
你可以直接在项目根目录下运行 CLI 指令安装官方组件：
```bash
npx shadcn add date-picker
```
CLI 会自动处理依赖和路径别名，并将组件安装至 `src/components/ui/`。

#### 2. 添加 Pixel-Perfect 动画与特效组件
本项目已集成 [vansh-nagar/Pixel-Perfect](https://github.com/vansh-nagar/Pixel-Perfect) 组件库注册表（使用 `@pixel-perfect` 命名空间）。如果需要引入其提供的高逼真动画与物理效果组件（如 3D 按钮、赛博朋克按钮等），可直接运行：
```bash
npx shadcn add @pixel-perfect/3d-button
```
项目目前已全局预装了该组件库的核心交互依赖（`gsap`、`@gsap/react`、`framer-motion`）。

> [!TIP]
> **CN 别名修复**：拉取组件后，如果出现类似 `Cannot find module '@/lib/cn'` 的导入错误，请将该行引用手动替换为本项目的标准工具别名路径：
> ```diff
> - import { cn } from "@/lib/cn";
> + import { cn } from "@/lib/utils";
> ```

#### 3. 使用 transitions.dev 精细微动效
当前项目已引入 [transitions.dev](https://github.com/Jakubantalik/transitions.dev) 生产级 CSS 动效框架：
* 全局动效变量定义在 `src/styles/app.css` 的 `:root` 部分（包含时长、缓动、模糊度等参数）。
* 项目中的 **明暗切换按钮 (ThemeToggle)** 已经成功重构并应用了 `.t-icon-swap` 动效。它通过双 DOM 图标节点和 `data-state` 控制，在点击明暗模式切换时，太阳与月亮图标会产生极其平滑柔和的**缩放、交叉淡隐和模糊过渡**效果。
* 所有加入的动效都自动尊重系统的**减少动效（prefers-reduced-motion）**偏好设置，为用户提供无障碍的动效回退体验。
