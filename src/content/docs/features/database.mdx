---
title: PostgreSQL 与 Drizzle
description: 当前数据层结构和开发约定。
---

项目使用 PostgreSQL 16、postgres.js 和 Drizzle ORM。

- `src/db/client.ts` 延迟创建连接池。
- `src/db/schema.ts` 是 schema 的唯一统一视图。
- 各业务表定义在对应 feature 中，使用 `drizzle-orm/pg-core`。
- `DATABASE_POOL_SIZE` 控制单进程最大连接数。

```ts
import { createDb } from '@/db/client'

const db = createDb()
```

服务端代码仍有部分 `createDb(env.DB)` 调用，这是迁移期的兼容签名；参数已被忽略，新代码使用无参数形式。

表结构变更流程见 [PostgreSQL 迁移](/docs/getting-started/migrations)。测试必须使用隔离数据库，禁止把自动化测试指向开发共享库或生产库。
