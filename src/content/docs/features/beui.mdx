**beUI**（开源仓库为 [starc007/ui-components](https://github.com/starc007/ui-components)）是一套专门针对 **React & Next.js** 构建的高保真、微交互动效组件库。

在本项目中，我们**严格遵循扁平现代（Flat Modern）及毛玻璃微质感（Glassmorphism）**的设计规范，绝不使用任何写实/拟物的厚度及三维实体材质。以下记录了 beUI 库中所有组件的动效表现、在“放映厅/主站”中的**适用时机 (Use Cases)**，供开发参考。

---

## 1. 表单与输入控制 (Form & Input Controls)

### Checkbox (复选框)
*   **动效特性**：手绘感的打勾路径动画（Draw-on checkmark）、按压时的物理弹簧收缩反馈、支持不确定状态（Indeterminate state）。
*   **什么时候可以用**：
    *   提名广场中的候选过滤条件复选框。
    *   用户后台待办清单（如“每周观影打卡清单”）的复选确认。

### Select (下拉选择)
*   **动效特性**：下拉面板从触发器边缘呈弹性展开（Bouncily unfolds），同时包含一种极具张力的 **Morph 变体**——触发器按钮在点击后共享布局（Shared layout）平滑放大成选择面板。
*   **什么时候可以用**：
    *   发起新提名表单中的“内容类型选择”（TV新番/剧场版/电影）。

### Radio Group (单选框组)
*   **动效特性**：选中指示圆点在不同单选项之间平滑“滑行游走”（使用 `framer-motion` 的 `layoutId` 跨节点移动），并带有按压弹性反馈。
*   **什么时候可以用**：
    *   影评评分星级单选组，或后台通知频率单选设置。

### Switch (开关)
*   **动效特性**：滑块滑行时带有弹性收缩与拉伸（Spring-driven thumb），按压时提供果冻式的微回弹。
*   **什么时候可以用**：
    *   设置面板中的“接收每周放映开始通知”或“开启暗黑模式”开关。

### Range Slider (范围滑动条)
*   **动效特性**：滑动条带有对准定位刻度点（Tick dots），滑块是一个高弹性的纵向指示条，在不同刻度之间“滑行卡合”（Snapped steps），支持无障碍的键盘微调和减少动效回退。
*   **什么时候可以用**：
    *   影评分数精细滑动条，让群友以 0.5 递增打出更精细的分数。

### Input (文本输入框)
*   **动效特性**：支持浮动 Label。当输入错误时触发“抖动”（Error shake），当输入正确或验证成功时，输入框右侧以线条绘制出成功对勾（Success check draw）。
*   **什么时候可以用**：
    *   用户登录界面的账号密码输入、提名表单中的海报链接校验。

## 2. 布局、折叠与弹窗 (Layout & Overlays)

### Popover (气泡弹出框)
*   **动效特性**：**Gooey 变体（粘性气泡）**：弹出面板像水滴般从触发按钮里“流淌渗出”（利用 SVG 粘性滤镜 Goo filter 制造拉扯和断裂效果），随后扁平文字在面板上渐渐浮现。
*   **什么时候可以用**：
    *   点击用户头像弹出的“快速个人名片”或“快捷设置气泡”。

### Bottom Sheet (底部抽屉面板)
*   **动效特性**：具有高惯性（Inertia）的移动端底部拉伸面板，支持平滑的手势拖拽、多档位吸附点（Snap points）以及玻璃质感的半透明背板。
*   **什么时候可以用**：
    *   手机端打开的“写影评”表单或“查看本期历史所有评论”。

### Drawer (侧边栏抽屉)
*   **动效特性**：从网页左侧或右侧平滑滑入的侧边栏。支持弹性过渡、背景高斯模糊（Backdrop blur）、阻断滚动（Scroll lock）以及 Esc 键退出。
*   **什么时候可以用**：
    *   放映会历史卡片右侧弹出的“详细吐槽聊天室”。

### Tooltip (文字提示)
*   **动效特性**：淡入淡出并附带模糊（Blur enter/exit）与轻微弹簧微缩放。
*   **什么时候可以用**：
    *   鼠标移入得票数时提示“每人每周仅有3票”。

### Morphing Modal (变形弹窗)
*   **动效特性**：卡片层级折叠。当在弹窗内的多个子视图间切换时，弹窗整体高度和宽度会随着子视图内容的大小**平滑形变收缩/扩张**，视图内容通过模糊交叉淡入（Blur cross-fade）进行切换。
*   **什么时候可以用**：
    *   多步骤表单：如“发起提名 ➜ 上传海报 ➜ 确认并支付投票积分”。

### Bouncy Accordion (弹性手风琴)
*   **动效特性**：加权的物理弹簧高度折叠面板，同一时间只允许展开一项，图标随之翻转，支持减少动效偏好。
*   **什么时候可以用**：
    *   FAQ 常见放映问题解答板块。

### Animated Toast Stack (堆叠通知气泡)
*   **动效特性**：通知气泡层层堆叠在底部，新通知滑入时会将旧通知向下/向后推并微缩，支持手势左滑删除（Swipe dismissal）与状态形变。
*   **什么时候可以用**：
    *   放映开始前的“广播系统消息”，或“投票成功！”的系统吐司通知。

## 3. 数据与导航展示 (Data & Navigation)

### Table (大数据表格)
*   **动效特性**：采用虚拟化列表（Virtualized），在处理 10000+ 条大数据行时依然保持流畅。支持表头平滑排序、行选中、列宽拖拽（Column resize）与拖拽重新排序（Reorder）。
*   **什么时候可以用**：
    *   管理员后台的“用户出勤表”或“所有提名历史数据库”。

### Tabs (选项卡)
*   **动效特性**：胶囊式或下划线选项卡，底部的 active 指示器会在点击不同 Tab 时像胶水一样平滑地“滑行”过去（使用 layoutId 弹性过渡）。
*   **什么时候可以用**：
    *   提名广场中的过滤切换：`全部提名 / TV新番 / 电影 / 我的提名`。

### Cylinder Carousel (圆柱体轮播图)
*   **动效特性**：将扁平卡片投影排布在虚拟圆筒的内侧，靠近中心时卡片远离并缩小，滑向边缘时卡片放大移近。支持鼠标拖动、滚动滚轮及左右键拨动，具有弹性惯性滑动。
*   **什么时候可以用**：
    *   首页最醒目的“本期候选佳作推荐”横向轮播。

### Marquee (无缝跑马灯)
*   **动效特性**：支持水平或垂直方向的无限无缝滚动，鼠标悬停时可自动暂停（Pause-on-hover）。
*   **什么时候可以用**：
    *   放映厅顶部的流动通告栏、合作伙伴/友情链接列表。

### Dock (悬浮工具栏)
*   **动效特性**：模仿 macOS 底部的 Dock。鼠标靠近时，扁平的 Icon 会根据光标距离平滑放大缩回，并带有滑行指示器。
*   **什么时候可以用**：
    *   前台放映厅的快速导航底栏（如首页、提名广场、看板、后台的快速切换）。

### Shared Layout Background (共享背景滑块)
*   **动效特性**：一个精美的毛玻璃胶囊滑块，在鼠标滑过菜单不同子项时，滑块会自动平滑“飘动”到对应项的下方，移出菜单时模糊淡隐。
*   **什么时候可以用**：
    *   导航栏菜单的 hover 态背景指示。

## 4. 视觉、反馈与特效 (Visuals & FX)

### Shader Background (着色器背景)
*   **动效特性**：包含 `mesh gradient` (极光渐变), `grain` (噪点颗粒), `warp` (液态扭曲), `waves` (矢量波浪), `voronoi` (泰森多边形) 和 `dot orbit` (点轨迹圆周) 等着色器。
*   **什么时候可以用**：
    *   全站底色背景：在深色主题下加入极微弱的 `grain`（电影噪点）和 `mesh gradient`，营造深夜影院的高端沉浸感。

### Loader (等待指示器)
*   **动效特性**：提供 17 种风格化等待状态，如 dot-matrix (点阵), morph (变形), metaballs (融球), scramble (乱码) 以及 5 种极客复古的 **Terminal 终端 ASCII 旋转符**。
*   **什么时候可以用**：
    *   页面加载或向 D1 提交评分数据时的 Loading 等待状态。

### Tilt Card (3D 悬浮卡片)
*   **动效特性**：鼠标悬停在卡片上时产生 3D 偏转透视，且卡片表面有一道追随光标的镜面玻璃反光（Glare）。
*   **什么时候可以用**：
    *   提名广场中高亮显示的作品海报卡片。

### Text Animation (文本动画)
*   **动效特性**：提供用于开场白（Reveal）的字符错落飞入、文字加载时的流光渐变（Shimmer text）以及字符翻滚替换效果。
*   **什么时候可以用**：
    *   倒计时上方的预告语以及看板标题的加载。

### Number Animation (数字动画)
*   **动效特性**：数字递增累加动画（Count-up）或数字翻滚滚动（Digit ticker）效果。
*   **什么时候可以用**：
    *   数据看板在展现历史均分、期数、投票总数时的跳动显现。

### Animated Badge (动画徽章)
*   **动效特性**：内置脉冲（Pulse）动效状态灯、带状态旋转 Icon 的徽章。
*   **什么时候可以用**：
    *   放映状态标记：`● 正在联播`（红灯闪烁脉冲）或 `● 已完结`。

### Action Swap (动作状态切换)
*   **动效特性**：在点击按钮时，按钮内部的文字和 Icon 会以模糊交叉淡入（Blur cross-fade）的形式在“加载中”、“已完成”、“确认”之间平滑更替。
*   **什么时候可以用**：
    *   点赞/投票按钮在“投票 ↔ 撤销”之间的极速无缝切换。

### Theme Toggle (视图过渡主题切换)
*   **动效特性**：利用浏览器最新的 **View Transition API**，在切换深浅模式时，整个页面的色彩变化会以一个从按钮处散开的**无缝圆形剪切路径（Clip-path reveal）**扩散到全屏。
*   **什么时候可以用**：
    *   后台右上角的明暗模式切换。

### Scroll Animation (滚动 Lenis 平滑驱动)
*   **动效特性**：基于 **Lenis** 的平滑滚动环境，提供全站平滑的弹性惯性滚动，并带有一条精准的阅读进度指示器。
*   **什么时候可以用**：
    *   由于放映历史 records 页面非常长，平滑滚动可以让浏览时间轴的体验成倍提升。

## 5. 安装与别名处理

所有组件均可使用 shadcn CLI 拉取：

```bash
# 拉取 Popover 气泡弹窗
npx shadcn add @starc007/ui-components/popover

# 拉取 Tabs 选项卡
npx shadcn add @starc007/ui-components/tabs
```

拉取后，将组件内所有引用外部类名合并方法的路径更改为本站标准：
```typescript
- import { cn } from "@/lib/cn";
+ import { cn } from "@/lib/utils";
```

## 6. AI Agent MCP 与注册表自动集成指南

beUI 提供了对 AI 编码代理（如 Antigravity, Claude Code, Cursor, Codex 等）极其友好的静态自动化接口。AI 助手可以直接通过连接 MCP 服务或调用 JSON API 端点，自动为您在项目中安装、修改和整合 beUI 的组件及全部依赖。

### A. 接入 beUI MCP 服务
将以下服务器接入到您的 AI 编码工具中，AI 助手将能自动调用工具（`list_components`、`search_components`、`get_component`、`get_install_command`）完成开发：

*   **MCP 终端路径**：`https://mcp.beui.dev/mcp`
*   **各客户端命令行注册**：
    ```bash
    # Claude Code
    claude mcp add --transport http beui https://mcp.beui.dev/mcp

    # Codex
    codex mcp add beui --url https://mcp.beui.dev/mcp

    # Amp
    amp mcp add beui https://mcp.beui.dev/mcp
    ```
*   **手动 JSON 配置 (`mcp.json`)**：
    ```json
    {
      "mcpServers": {
        "beui": {
          "type": "http",
          "url": "https://mcp.beui.dev/mcp"
        }
      }
    }
    ```

### B. 核心 API 端点与自动化流程
如果 AI 助手无法直接使用 MCP，可以直接调用以下原始 API：

*   `GET https://beui.dev/r`：获取全量组件的 JSON 目录列表。
*   `GET https://beui.dev/r/{slug}`：拉取对应组件的详细元数据（含外部依赖、内联工具函数文件、全部 TSX 内容）。
*   `GET https://beui.dev/r/{slug}/raw`：获取纯 TSX 源码文本，适合直接写入文件。
*   `GET https://beui.dev/registry.json`：与 shadcn CLI 兼容的组件包目录目录。

### C. 代理安装工作流 (Agent Workflow)
AI 助手在得到您的授权后，只需四步即可在本地全自动部署新组件：
1.  **查找组件**：请求 `https://beui.dev/r` 目录，验证对应组件（如 `animated-toast-stack`）是否存在。
2.  **拉取详情**：请求 `https://beui.dev/r/{slug}`，获取需要写入的本地路径和外部 `dependencies`。
3.  **写入本地**：自动在本地对应的路径（如 `src/components/ui/`）执行 `writeFile` 创建代码文件。
4.  **安装外部包**：自动在本地执行 `pnpm add`（或 bun/npm）安装组件的依赖包。

### D. shadcn 指令自动化安装
对于支持直接读取远程 JSON 定义的 shadcn CLI，AI 助手也可以一键安装：
```bash
# 自动下载定义，安装组件源文件并自动拉取 npm 外部依赖
npx shadcn@latest add https://beui.dev/r/{slug}.json
```
