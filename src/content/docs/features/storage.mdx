---
title: 本地文件存储
---

当前上传文件写入 `UPLOAD_DIR`。生产 Compose 将该目录映射到 `uploads` volume。

主要实现位于 `src/features/storage/storage.server.ts`：

- 对对象 key 做路径归一化和目录穿越检查。
- 头像与群身份图片在写入前校验 MIME 类型和大小。
- API 路由读取私有文件并返回保存的 Content-Type。

本地默认目录是 `./uploads`；容器内是 `/app/uploads`。

此实现适合单机或共享 volume 部署。扩展到多实例前，需要迁移到 S3/R2 等共享对象存储，并保持相同的校验、私有访问和缓存语义。
