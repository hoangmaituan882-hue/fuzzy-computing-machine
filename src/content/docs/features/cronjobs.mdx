---
title: 定时任务
description: 在 Node/Docker 部署中运行维护任务。
---

`src/features/maintenance/cleanup.ts` 提供清理过期 session、verification、限流记录和 webhook 标记的领域逻辑。

当前 Node 入口不会自动调度它。生产环境应使用 1Panel 计划任务、系统 cron 或独立 job 容器触发一个专用脚本。接线时需要：

- 注入与应用相同的 `DATABASE_URL`。
- 使用 PostgreSQL advisory lock，避免多实例重复执行。
- 记录开始、结束、删除数量和失败原因。
- 为耗时与删除数量设置告警阈值。

旧 `src/worker.ts` 中的 `scheduled()` 只属于历史 Cloudflare 实现，不会在 Docker 部署中触发。
