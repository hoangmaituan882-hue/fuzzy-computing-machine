---
title: Docker 与 1Panel 部署
---

当前生产方案是 Node.js + PostgreSQL + 本地持久化文件，推荐使用仓库根目录的 `docker-compose.yml`。

## 1. 环境文件

```bash
cp .env.1panel.example .env
```

必须修改：

```dotenv
POSTGRES_PASSWORD=强随机密码
BETTER_AUTH_SECRET=至少32位随机字符串
BETTER_AUTH_URL=https://你的域名
ADMIN_EMAILS=管理员邮箱
```

## 2. 构建并启动

```bash
docker compose up -d --build
docker compose logs -f app
```

应用容器每次启动会先执行 `pnpm db:migrate` 的底层脚本，然后启动 `server/serve.mjs`。已执行迁移记录在 PostgreSQL 的 `_app_migrations` 表。

## 3. 反向代理

将域名代理到：

```text
http://127.0.0.1:3000
```

代理必须传递真实的 `Host` 与 `X-Forwarded-Proto`，否则认证回调 URL 和 Secure Cookie 判断可能错误。

## 4. 持久化与备份

- `postgres-data`：数据库
- `uploads`：头像和群身份图片

升级或重建容器前备份 PostgreSQL，并且不要执行 `docker compose down -v`。数据库 schema 变更必须使用新的 SQL 迁移文件，不能修改已经执行的迁移。

Cloudflare Wrangler workflow 已不属于当前部署路径。
