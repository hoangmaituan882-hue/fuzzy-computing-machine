title: PostgreSQL 迁移
---

Schema 使用 Drizzle `pg-core` 定义，统一从 `src/db/schema.ts` 导出。

## 生成迁移

```bash
pnpm db:generate
```

检查 `drizzle/postgres/` 中新生成的 SQL，尤其关注删除列、类型转换、唯一索引和外键对现有数据的影响。

## 应用迁移

```bash
pnpm db:migrate
```

迁移器会：

1. 获取 PostgreSQL advisory lock，避免多个应用实例并发迁移。
2. 按文件名顺序读取 `drizzle/postgres/*.sql`。
3. 在事务中执行未应用文件。
4. 将文件名与 SHA-256 写入 `_app_migrations`。
5. 已执行文件内容发生变化时立即失败。

因此迁移是只向前追加的。不要编辑已经在任何环境执行过的 SQL；修复必须新增下一个迁移。

生产变更前先备份数据库，并在同版本 PostgreSQL 的临时库验证迁移。
