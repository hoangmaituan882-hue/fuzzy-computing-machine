---
title: 环境变量
description: Node.js 与 PostgreSQL 运行环境配置。
---

本地脚本通过 Node.js 的 `--env-file-if-exists=.env` 读取根目录 `.env`。生产环境由 Docker Compose 或进程管理器注入变量。

| 变量 | 必需 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | 是 | PostgreSQL 连接串 |
| `DATABASE_POOL_SIZE` | 否 | postgres.js 最大连接数，默认 10 |
| `UPLOAD_DIR` | 否 | 上传文件目录，默认 `./uploads` |
| `BETTER_AUTH_SECRET` | 是 | 至少 32 个字符 |
| `BETTER_AUTH_URL` | 是 | 应用公网地址；本地为 `http://localhost:3004` |
| `ADMIN_EMAILS` | 否 | 逗号分隔的管理员邮箱 |
| `RESEND_API_KEY` / `EMAIL_FROM` | 否 | 邮件发送；留空使用开发降级路径 |
| `GOOGLE_CLIENT_ID/SECRET` | 否 | Google OAuth，必须成对设置 |
| `GITHUB_CLIENT_ID/SECRET` | 否 | GitHub OAuth，必须成对设置 |
| `STRIPE_SECRET_KEY` | 否 | Stripe 服务端密钥 |
| `STRIPE_WEBHOOK_SECRET` | 条件 | 配置 Stripe 时必须设置 |
| `STRIPE_PRICE_PRO_*` | 否 | Pro 月付、年付、终身价格 ID |
| `TURNSTILE_SITE_KEY/SECRET_KEY` | 否 | Turnstile，必须成对设置 |
| `CF_ANALYTICS_TOKEN` | 否 | Cloudflare Web Analytics 前端 beacon token |
| `SENTRY_DSN` | 否 | 保留配置；Node 端 Sentry 仍待重新接线 |

环境值统一从 `src/lib/env.ts` 读取。除该文件外，源码禁止直接访问 `process.env`。
