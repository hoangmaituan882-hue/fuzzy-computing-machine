---
title: 本地安装与启动
---

## 前置条件

- Node.js 22+
- pnpm 10+
- Docker 与 Docker Compose

## 1. 安装依赖

```bash
pnpm install
```

## 2. 创建本地环境文件

```bash
cp .env.example .env
```

至少确认以下值：

```dotenv
DATABASE_URL=postgres://galgame:galgame_password@localhost:5432/galgame
BETTER_AUTH_SECRET=至少32位随机字符串
BETTER_AUTH_URL=http://localhost:3004
```

## 3. 启动 PostgreSQL

```bash
docker compose -f docker-compose.dev.yml up -d
```

开发数据库只绑定到 `127.0.0.1:5432`，不会对局域网公开。

## 4. 应用迁移

```bash
pnpm db:migrate
```

## 5. 启动应用

```bash
pnpm dev
```

访问 [http://localhost:3004](http://localhost:3004)。

## 停止本地数据库

```bash
docker compose -f docker-compose.dev.yml down
```

不加 `-v` 会保留 `postgres-dev-data` volume 中的数据。
