---
title: 代码结构
---

项目采用按业务垂直切片的 TanStack Start 全栈结构。

```text
src/
  server.ts                 Node/TanStack 服务端入口
  routes/                   页面、API 与文件路由
  features/screening/       竞猜和放映核心领域
  features/auth/            Better Auth
  features/billing/         Stripe 与权益
  features/storage/         本地文件存储
  features/admin/           管理后台
  db/client.ts              PostgreSQL Drizzle 客户端
  db/schema.ts              全部表的统一导出
  content/docs/             Fumadocs 文档
server/serve.mjs            生产 Node HTTP 适配器
drizzle/postgres/           PostgreSQL SQL 迁移
```

## 请求路径

1. `server/serve.mjs` 处理静态文件，并把动态请求转换为 Web `Request`。
2. `src/server.ts` 校验环境变量并统一附加安全响应头。
3. TanStack Router 执行 route loader、server function 或页面 SSR。
4. 领域服务通过 `src/db/client.ts` 访问 PostgreSQL。

## 领域边界

页面文件负责加载、交互状态和展示；授权、输入校验、唯一性和状态转换必须落在 server function 或领域服务中，不能只依赖表单限制。
