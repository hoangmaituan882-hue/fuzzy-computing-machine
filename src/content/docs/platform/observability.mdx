## Web Analytics

设置 `CF_ANALYTICS_TOKEN` 后，根页面会注入 Cloudflare Web Analytics beacon。这个 token 是公开站点标识，不是服务端密钥。

## 服务日志

Node 入口和迁移器目前使用结构较轻的控制台日志。生产至少应收集：

- HTTP 5xx 与响应时间
- Better Auth 登录/回调失败
- PostgreSQL 连接与迁移失败
- Stripe webhook 验签和重试
- Resend 发送失败
- Bangumi 上游错误和缓存命中情况

日志不得输出密码、Cookie、OAuth token、Stripe secret 或匿名 participant ID。

## Sentry 状态

`SENTRY_DSN` 仍保留在环境模型中，但原有 `@sentry/cloudflare` 包装只存在于旧 Worker 入口。Node 生产入口尚未重新接入适合 Node 的 Sentry SDK，因此不能把“设置 DSN”视为已经启用错误上报。
