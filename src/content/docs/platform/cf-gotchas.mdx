这个文件名来自旧 Cloudflare 文档，为避免已有链接失效暂时保留。

## 当前事实

- 生产运行时是 Node.js 22，不是 workerd。
- 数据库是 PostgreSQL，不是 D1。
- 上传写入 `UPLOAD_DIR`，不是 R2。
- `src/server.ts` 是有效服务端入口；`src/worker.ts` 是待删除的迁移参考。
- Docker/1Panel 是当前部署路径；Wrangler workflow 不应再用于发布。

## Node 入口注意事项

`server/serve.mjs` 必须正确转发多个 `Set-Cookie`，并尊重反向代理传入的 host/protocol。应用级环境校验和安全头在 `src/server.ts` 中执行。

## 定时清理

旧 Worker 的 `scheduled()` 不会在 Node 部署中运行。`src/features/maintenance/cleanup.ts` 仍保留领域逻辑，但需要接入 1Panel 计划任务、系统 cron 或独立 worker，并确保同一时刻只有一个实例执行。
