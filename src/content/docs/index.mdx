## 当前迁移状态

仓库由 Cloudflare/D1 模板迁移而来。旧 Wrangler、Worker 和 D1 测试文件仍暂时保留，但当前生产入口是 Node.js，数据库是 PostgreSQL，上传文件保存在本地目录或 Docker volume。

新代码不要继续依赖 D1、R2 或 Miniflare。完整约定以仓库根目录的 `AGENTS.md` 为准。
